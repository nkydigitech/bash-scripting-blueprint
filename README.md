Master Bash scripting from your first terminal command to practical automation.

This free, self-paced blueprint takes you from **absolute beginner to confident Bash practitioner** through guided lessons, hands-on labs, checkpoints, quizzes, troubleshooting, and a final DevOps automation project.

You do not need to buy a course to follow this training.

## What You Will Learn

- Terminal and shell fundamentals
- Files and directories
- Bash scripts and executable permissions
- Variables and user input
- Conditionals
- Loops
- Functions
- Pipes and redirection
- Text processing with `grep`, `cut`, `sort`, `uniq`, `awk`, and `sed`
- Exit codes and error handling
- Safe Bash scripting
- Debugging
- DevOps automation
- A practical final project

## How To Use This Repository

Start at **[00 - Before You Start](./00-before-you-start/README.md)**.

Do not rush through the modules.

For each lesson:

1. Read the concept.
2. Run the commands yourself.
3. Compare your result with the expected result.
4. Complete the exercise without looking at the solution.
5. Use the checkpoint to test your understanding.
6. Complete the quiz.
7. Move to the next module.

The goal is not to memorize commands.

The goal is to understand what you are doing and eventually automate tasks yourself.

## Prerequisites

You need:

- A computer
- Internet access for setup resources
- A terminal
- Basic ability to create and edit files

You do **not** need previous Bash programming experience.

Linux, macOS, WSL, and Git Bash are covered with platform notes where relevant.

## Cost

This blueprint is designed to be free.

Most lessons run locally and do not require AWS, Azure, or other paid cloud resources.

When a lab can create cloud costs, the lesson will clearly warn you and include cleanup guidance.
