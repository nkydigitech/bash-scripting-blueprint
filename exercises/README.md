# Exercises

Use these after completing the modules.

## Exercise 1 — Personal Lab

Create:

```text
my-bash-lab/
├── scripts/
├── data/
├── logs/
└── reports/
```

## Exercise 2 — Greeting Script

Write a script that asks for a name and greets the user.

## Exercise 3 — File Checker

Accept a filename as an argument and report whether it exists.

## Exercise 4 — Server List

Read server names from a file and print a check message for each one.

## Exercise 5 — Log Report

Given:

```text
web1,200
web2,500
web3,404
web4,200
```

produce a report containing only non-200 responses.

## Exercise 6 — System Summary

Build a script that displays:

- username
- hostname
- current directory
- date
- disk usage

## Rule

Attempt each exercise before looking for a solution.
