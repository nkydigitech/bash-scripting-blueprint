# Quiz — Terminal Basics

Try these without looking back at the lesson.

## Questions

1. What command prints the current working directory?
2. What command lists files?
3. What does `cd ..` do?
4. What does `mkdir` do?
5. What does `touch` commonly do?
6. What command displays the contents of a text file?
7. What is the difference between `>` and `>>`?
8. Why should `rm` be used carefully?

## Answers

1. `pwd`
2. `ls`
3. Moves to the parent directory.
4. Creates a directory.
5. Creates an empty file if the file does not already exist.
6. `cat`
7. `>` replaces/creates output; `>>` appends output.
8. It can permanently remove files.
