# Contributing

This repository is a free learning resource.

If you find:

- a broken command
- unclear instructions
- a factual error
- a platform-specific issue
- a typo

please open an issue or submit a pull request.

When reporting a problem, include:

1. Operating system
2. Shell/version
3. Command you ran
4. Actual output/error
5. Expected result

Keep contributions beginner-friendly and technically accurate.
